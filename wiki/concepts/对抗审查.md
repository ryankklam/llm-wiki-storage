# 对抗审查

## 定义

**对抗审查（Adversarial Review）是让另一个子 Agent 专门挑错的验证机制**，拆解最终答案里的所有假设，检查逻辑一致性。

## 工作方式

拆解最终答案里的所有假设：
- 用了哪张表
- 过滤条件有没有漏
- 时间窗口是不是对
- 指标口径是不是一致

## 效果与代价

| 指标 | 变化 |
|------|------|
| 准确率 | +6% |
| Token 消耗 | +32% |
| 延迟 | +72% |

## 使用策略

- 不适合每个问题都开
- 高风险问题值得开
- 低风险问题不一定值得
