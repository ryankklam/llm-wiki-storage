# Anthropic Prompt技巧

## 定义

**Anthropic Prompt技巧是 Anthropic 官方推荐的 Prompt 编写最佳实践**，由 Anthropic 应用 AI 工程师在实际客户案例中总结得出。这些技巧涵盖了 Prompt 维护和 Agent 构建两个核心场景。

## 核心原则

### 1. 结构化 Prompt

使用 XML tags 分离不同类型的内容：
- `<role>` - 角色定义
- `<guidelines>` - 通用指南
- `<policy>` - 政策规则
- `<tone>` - 语气要求
- `<data>` - 数据输入
- `<output>` - 输出格式

**经验法则**：如果你在阅读 Prompt 时无法区分指南、政策和数据，模型很可能也无法区分。

### 2. 创建输出契约

- 定义清晰的输出格式
- 使用 XML tags 标记输出
- 配合 Stop Sequence 确保输出一致性
- 对于复杂输出结构，使用结构化输出（Structured Outputs）

### 3. 清理遗留补丁

- 删除针对旧模型的冗余指令
- 追踪防御性更改的原因（版本控制）
- 定期审查"永远不要"类指令是否仍然必要

### 4. 说明权衡的两面

不只说成本，也要说收益。例如：
- 错误做法：升级案例花费 8 美元，会计入快速解决指标
- 正确做法：升级案例花费 8 美元，但如果弄错会损失退款和客户信任

## 评估套件设计

### 三种关键测试用例

1. **控制用例（Control Case）**
   - 应该总是通过
   - 明确无误的情况
   - 用于验证基本功能

2. **边缘用例（Edge Cases）**
   - 之前看到模型失败的用例
   - 通过加入指令防止问题再次出现

3. **能力边界用例**
   - 测试模型是否知道何时转交人工
   - 测试模型是否知道何时拒绝回答

## 常见反模式

| 反模式 | 问题 | 正确做法 |
|--------|------|----------|
| 告诉模型它是人类 | 不真实 | 准确定义角色 |
| 复制网站内容到 Prompt | 包含无关信息（如 hero 图片、cookies） | 清理冗余内容 |
| 所有指令混在一个大段落 | 模型无法区分 | 使用 XML tags 分离 |
| 过度防御性的"永远不要"指令 | 导致信息扣留 | 给出平衡的指令 |
| 告诉模型做好工作但不给工具 | 指令不增加能力 | 提供工具支持 |

## 关键教训

### 指令不增加能力

告诉模型"正确计算很关键"并不会让它更擅长心算。正确的方法是：
- 提供工具（如 calculate_proration 工具）
- 定义工具模式（Tool Schema）
- 让模型在需要时调用工具

### 模型可能扣留信息

不只是幻觉（编造事实），过度优化也可能导致信息扣留。例如：
- 模型被告知"永远不要给错误信息"
- 结果：模型拒绝提供它实际上有权限访问的信息
- 解决：给出平衡的指令，说明信息来源

## Agent 构建策略

根据任务复杂度选择策略：

| 任务类型 | 推荐方案 | 特点 |
|----------|----------|------|
| 简单任务 | 小模型 + 好 Prompt | 成本低、速度快 |
| 复杂推理 | 大模型 + Extended Thinking | 可靠但成本高 |
| 高可靠性 | 生成-评估-修复循环 | 最佳方案 |
