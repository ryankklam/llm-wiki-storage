# MicroVM

> **领域**：系统安全 / 虚拟化
> **代表产品**：AWS Firecracker

## 定义

**MicroVM**（微虚拟机）是用硬件虚拟化造一道硬件强制边界，但把虚拟机做得极轻的沙箱技术。

## 代表：Firecracker

AWS 开源的 MicroVM 技术，同时服务 Lambda 和 Fargate。

### 三个关键数字

| 指标 | 数值 |
|------|------|
| 启动时间 | < 125ms |
| 单台内存开销 | < 5MB |
| 单机创建密度 | 150 台/秒 |

## 为什么又安全又轻

靠**极致裁剪**：
- 砍掉 Serverless 用不上的 BIOS、PCI、USB、GPU
- 设备越少，攻击面越小
- 不做完整的硬件初始化，启动自然快

## 核心优势

- 独立 guest 内核，需要突破 Hypervisor 才能逃逸
- 隔离强度接近传统虚拟机
- 性能密度接近容器

## 适用场景

需要**兼容性 + 强隔离**的场景。
