# Prompt

## 定义

**Prompt 是大模型的单次指令输入**，是大模型1.0时代 Prompt 工程的核心产物。它本身不创造任何新能力，只是把大模型已有的能力激发出来。

## 核心特征

### 技术定位
- **时代**：大模型1.0时代
- **工程**：Prompt工程
- **核心逻辑**：一次性告诉模型所有事

### 局限性
- **非标准化**：同一条 Prompt，换个大模型、换个上下文，输出效果可能天差地别
- **强依赖上下文**：无法脱离具体场景复用
- **不可自主调用**：只能由用户手动输入，无法被 Agent 工作流自主识别触发
- **无兜底能力**：容错率为0，无异常处理能力

## 与 Skill 的关系

> **Prompt 只是 Skill 众多组成模块中的一个可选环节**

Prompt 永远无法跳出大模型本身，去调取外部工具、读写文件、对接企业系统。而 Skill 是整合了 Context 工程、工具、流程的完整业务解决方案。

## 关键信息
- Prompt 的本质是引导大模型的输出方向（来源：[[2026-05-11-万物都可蒸馏Skill-5min讲清机制]]）
- 所有信息一次性全部喂给模型，让模型在单次推理中完成所有任务
