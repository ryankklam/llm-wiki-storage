# BCrypt

## 定义

BCrypt 是一种基于 Blowfish 密码算法的自适应哈希函数，专门设计用于安全存储密码。由 Niels Provos 和 David Mazières 于 1999 年在 USENIX 会议上提出，是当今业界最主流的密码哈希算法之一。

## 核心设计思想

BCrypt 的核心思想与 MD5 等快哈希**反着来**——故意设计得很慢。（来源：[[2026-07-03-面试问密码怎么存答MD5直接被淘汰]]）

| 场景 | 体验 |
|------|------|
| 正常用户登录 | 只验一次，慢个0.0几秒完全无感 |
| 攻击者暴力破解 | 每次多花时间，几十亿次尝试成本直接上天 |

## 关键特性

### 1. 计算成本因子（Work Factor）
BCrypt 的"慢多少"可以通过成本因子（也叫迭代次数、工作因子/Work Factor）调节。随着硬件性能提升，可以逐步调高成本因子，始终保持破解难度。（来源：[[2026-07-03-面试问密码怎么存答MD5直接被淘汰]]）

### 2. 内置盐（Salt）
BCrypt 把盐直接内置在最终的哈希结果中，开发者不需要自己单独存储盐。验证时只需用同样的参数再算一遍比对即可。（来源：[[2026-07-03-面试问密码怎么存答MD5直接被淘汰]]）

### 3. 自包含格式
BCrypt 的输出字符串自包含算法标识、成本因子、盐和哈希值，工程上最省心。（来源：[[2026-07-03-面试问密码怎么存答MD5直接被淘汰]]）

## BCrypt 输出格式示例

```
$2a$10$N9qo8uLOickgx2ZMRZoMy.Mqrqhm2E9K0MqD2K9R1F0YQJqC0Jy6C
  |   |  |                        |
  |   |  |                        └─ 哈希值
  |   |  └─ 22字符的随机盐（Base64编码）
  |   └─ 成本因子（10 = 2^10 轮迭代）
  └─ 算法版本标识
```

## 同类算法对比

| 算法 | 特点 | 适用场景 |
|------|------|----------|
| BCrypt | 业界主流，成熟稳定，内置盐 | 通用密码存储首选 |
| SCrypt | 内存困难型，抗ASIC/FPGA | 对硬件攻击有更高要求 |
| Argon2 | 密码学竞赛冠军，现代最强 | 新项目推荐 |
| PBKDF2 | NIST推荐，可配置迭代次数 | 合规要求场景 |
