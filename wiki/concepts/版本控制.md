# 版本控制

## 定义

**版本控制（Version Control）**在 AI 编程语境下，不仅指 Git 等代码版本管理工具，还包括对 AI 行为的技术栈版本约束——在 rules.md / CLAUDE.md 中明确写出具体版本号，防止 AI 自行选择最新版本导致依赖冲突。

## 核心特征

### 技术栈版本约束
来源：[[2026-06-12-企业AI项目rules红线]]

- **写具体版本号**：如 React 19、Tailwind CSS v4、Python 3.11
- **不写版本号的后果**：AI 会自己挑一个最新的，踩过坑的人都懂
- **依赖冲突**：版本不匹配导致依赖冲突，回滚就是一个通宵

### AI 工具中的版本管理
- Specate 等工具内置 Git 分支管理
- 每个新需求当作 Feature，通过独立 Git 分支在后台处理
- 插件市场可安装 RQ（归档）相关命令插件

## 关键信息

- 技术栈不写名字，写具体版本号。不写版本号，AI 会自己挑一个最新的，踩过坑的人都懂。依赖冲突一冒头，回滚就是一个通宵。（来源：[[2026-06-12-企业AI项目rules红线]]）
- 不同版本语法和接口兼容都不一样，如 Python 3.9 和 Python 3.12 很多语法不同
