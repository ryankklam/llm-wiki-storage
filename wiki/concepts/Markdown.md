# Markdown

## 定义

**Markdown**是 AI 项目规范文件（rules.md / CLAUDE.md）的标准格式。作为轻量级标记语言，它既便于人类阅读，又便于 AI 解析，是项目规则文件的首选格式。

## 核心特征

### 为什么用 Markdown 写规则
- **可读性**：人类和 AI 都能轻松阅读
- **结构化**：通过标题、列表、代码块等组织规则
- **通用性**：Claude Code、Cursor 等工具都支持
- **版本友好**：与 Git 版本控制配合良好

### 规则文件的 Markdown 结构
来源：[[2026-06-12-企业AI项目rules红线]]

1. 项目定位（是什么、不是什么）
2. 技术栈约束（具体版本号）
3. 代码规范（复用策略、目录规范）
4. 质量约束
5. 禁止项（红线规则）
