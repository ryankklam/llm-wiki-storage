# API

## 定义

**API（应用程序接口）**在 AI 编程语境下，是 AI 生成代码中需要严格规范的部分。rules.md / CLAUDE.md 中应明确 API 接口规范、模型选择、环境变量管理等约束，防止 AI 随意更改接口定义或泄露 API Key。

## 核心特征

### AI 项目中的 API 规范
- **模型固定**：在 rules.md 中明确指定使用的 AI 模型
- **API Key 管理**：必须放在环境变量中，禁止写死在代码里
- **接口约束**：API 调用方式、参数规范应在规则中明确

### 与 rules.md 的关系
- API 相关约束是 rules.md 的重要组成部分
- 开发环境的 API Key 问题必须在规则中解决
- 接口规范约束防止 AI 随意更改 API 定义

## 关键信息

- AI 接口固定用指定模型，API Key 要放在环境变量里面（来源：[[2026-06-12-企业AI项目rules红线]]）
- 即使是约束，API Key 管理也是不可以商量的
