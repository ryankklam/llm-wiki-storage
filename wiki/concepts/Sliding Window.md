# Sliding Window

## 定义

**滑动窗口（Sliding Window）** 是短期记忆管理中最直接的方法：保留最近N轮对话，太早的内容先移出去。

## 工作原理

```
[对话1] [对话2] [对话3] [对话4] [对话5] ← 窗口大小=5
                              ↑ 新对话进入
[对话2] [对话3] [对话4] [对话5] [对话6] ← 对话1被移出
```

## 局限性

只靠滑动窗口不够，因为：
- 有些早期约束很关键（如"不要改数据结构"）
- 会丢失重要上下文信息

## 解决方案

结合其他策略使用：
- **摘要压缩**：对移出的内容做摘要
- **事实抽取**：保留关键约束和结论
- **优先级队列**：重要信息单独保留

## 适用场景

- 简单对话场景
- 对历史依赖较低的会话
- 作为更复杂策略的基础组件
