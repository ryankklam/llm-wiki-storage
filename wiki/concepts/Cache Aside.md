# Cache Aside

## 定义
Cache Aside（旁路缓存）是最常用的缓存策略模式。应用程序直接与缓存和数据库交互，缓存不主动做任何操作。

## 读取流程
1. 先查缓存，命中则直接返回
2. 缓存未命中则查数据库
3. 将数据库结果写入缓存
4. 返回结果

## 写入流程
1. 先更新数据库
2. 再删除缓存（注意是删除而非更新）

## 为什么写操作是删缓存而不是更新缓存
- 删除缓存是懒加载思想，下次读取时再加载最新数据
- 避免并发写导致的数据不一致
- 减少不必要的缓存更新（有些数据更新后可能不会被读取）

## 与其他缓存模式的区别

| 模式 | 特点 |
|------|------|
| Cache Aside | 应用代码直接管理缓存，最常用 |
| Read Through | 缓存层封装读取逻辑，应用只与缓存交互 |
| Write Through | 缓存层封装写入逻辑，同步更新缓存和数据库 |
| Write Behind | 先写缓存，异步批量更新数据库 |
