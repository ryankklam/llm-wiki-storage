# 知识图谱

## 定义

知识图谱（Knowledge Graph）是一种用节点和边来存储知识的图结构数据系统。在 AI Agent 长期记忆中，它特别擅长处理实体之间的复杂关系查询。

## 关键信息

### 工作原理
- 用**节点**表示实体（人、事件、概念等）
- 用**边**表示实体之间的关系
- 支持复杂的关系查询，如"谁和谁是什么关系"

### 优点
- 擅长处理复杂的关系查询
- 可以做事件关系的推理（时间推理、因果推理、假设推理）
- 与向量数据库互补，增强关系表达能力

### 缺点
- 构建和维护成本较高
- 需要专业的图数据库支持

### 在阿里云方案中的应用
- RDS PostgreSQL + Apache AGE：支持图数据库
- PolarDB Mem0：集成 Graph Memory，原生支持知识图谱
- PolarDB Agent Mem0：实体和事件三元组做知识图谱，支持深度推理

### 时间知识图谱
- Zap 框架引入了时间的知识图谱
- 每个记忆加上有效时间和记录时间两个时间戳
- 可以处理时间的时效性和时间的关系
