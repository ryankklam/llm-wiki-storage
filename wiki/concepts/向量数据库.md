# 向量数据库

## 定义

向量数据库是一种专门用于存储和检索高维向量数据的数据库系统。在 AI Agent 长期记忆中，它通过 Embedding 模型将文本转换为高维向量，然后利用余弦相似度进行语义检索。

## 关键信息

### 工作原理
1. 文本通过 Embedding 模型转换为高维向量
2. 通过余弦相似度找到语义相近的记忆
3. 即使表述完全不同，也能找到相关内容

### 优点
- 语义检索能力强，表述不同也能匹配
- 是目前最常用的长期记忆存储方式

### 缺点
- 对于实体之间的复杂关系表达能力较弱
- 需要结合知识图谱来增强关系查询能力

### 主流产品
- Chroma
- Pinecone
- Milvus
- Elasticsearch（支持向量检索）
- PGVector（PostgreSQL 扩展）

### 在阿里云方案中的应用
- RDS PostgreSQL + PGVector：支持向量检索
- PolarDB Mem0：向量+图+Rerank 混合检索
- PolarDB Agent Mem0：自研向量引擎 + 知识图谱双模存储
