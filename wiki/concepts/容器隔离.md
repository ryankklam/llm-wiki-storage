# 容器隔离

> **领域**：容器技术 / 系统安全

## 定义

**容器隔离**是基于 Linux 内核机制的轻量级隔离技术。容器本质上是宿主机上的一组普通进程，通过 Namespaces 和 Cgroups 等机制实现隔离。

## 核心机制

| 机制 | 作用 |
|------|------|
| **Namespaces** | 改变进程视野（PID、Network、Mount等） |
| **Cgroups** | 限制资源使用（CPU、内存、IO） |
| **Capabilities** | 切碎 root 权限 |
| **Seccomp** | 过滤系统调用 |
| **LSM**（AppArmor/SELinux） | 强制访问控制 |

## 核心特征

- 容器和宿主机之间**只有一个系统调用的距离**
- 容器与宿主共享同一个内核
- 内核中的任何提权漏洞都等于容器逃逸

## 风险

经典案例：**Dirty COW**（写时复制漏洞），普通进程就能提权到 root，容器边界形同虚设。

## 天花板

再多的 Seccomp 和 LSM 都改变不了一个事实：**系统调用最终还是由那个单体内核执行**。这就是容器隔离的天花板。

## 适用场景

需要**兼容性 + 高密度**的场景，接受内核漏洞风险。
