# Prompt工程

## 定义

**Prompt工程是大模型1.0时代的核心技术**，核心逻辑是**告诉模型怎么做**。通过精心设计的自然语言指令，提升大模型生成特定内容的概率。

## 核心特征

### 技术定位
- **时代**：大模型1.0时代
- **核心逻辑**：告诉模型怎么做
- **本质**：引导大模型的输出方向

### 工作方式
- 所有信息一次性全部喂给模型
- 让模型在单次推理中完成所有任务

## 局限性

1. **上下文太长会挤占窗口**
2. **关键信息被淹没**
3. **大模型容易走神、漏项长文本**
4. **处理准确率大幅下降**
5. **一旦出错只能全部重跑**

## 与 Context工程的演进

Prompt工程 → Context工程

- 从"一次性告诉模型所有事"到"在正确时机给正确信息"
- 从"单次推理"到"渐进式披露"

## Anthropic 官方最佳实践

### 评估驱动开发
- 建立评估套件（控制用例、边缘用例、能力边界用例）
- 针对失败模式逐一优化
- 使用评估验证改进效果

### 常见反模式
- 告诉模型它是人类
- 复制网站内容到 Prompt
- 所有指令混在一个大段落
- 过度防御性的"永远不要"指令
- 告诉模型做好工作但不给工具

### Agent 构建策略
- 简单任务：小模型 + 好 Prompt
- 复杂推理：大模型 + Extended Thinking
- 高可靠性：生成-评估-修复循环
