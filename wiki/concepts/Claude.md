# Claude

## 定义

**Claude**是 Anthropic 公司开发的大语言模型系列。在 AI 编程领域，Claude Code 是基于 Claude 的 Coding Agent 产品，支持通过 CLAUDE.md 文件进行项目级规则约束。Claude Code 本身是黑盒，需要通过 Spec-Kit 等文档驱动框架来让人类掌控开发进度。

## 关键信息

- Claude Code 的 CLAUDE.md 是项目规则文件，本质与 rules.md、Cursor Rules 相同（来源：[[2026-06-12-企业AI项目rules红线]]）
- Claude（以及 Codex）更喜欢新建代码而不是复用现有代码，这是 AI 的固有问题（来源：[[2026-06-12-企业AI项目rules红线]]）
- Claude 是 Spec-Kit 框架的主要底层模型之一（来源：[[2026-06-17-AI编程交付企业级项目SpecKit]]）
