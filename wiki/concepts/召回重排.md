# 召回重排

## 定义

**召回重排（Retrieve & Rerank）**是一种两阶段检索策略，在Agent Skill路由中指：先用轻量级检索方法（如Embedding相似度、关键词匹配）从大量Skill中召回少量候选（Top K），再用大模型做最终精排和选择。这与RAG（检索增强生成）的核心思路完全一致。

## 核心思想

> 不要让大模型直接从几百个Skill里选，先用Embedding或关键词检索召回Top 10，再交给大模型做最终判断。

### 两阶段架构

```
用户请求
    ↓
[召回阶段] Embedding / 关键词检索 / 向量检索
    ↓
Top K 候选Skill（如Top 10）
    ↓
[重排阶段] LLM精排 / 语义匹配
    ↓
最终选择的Skill
```

## 召回阶段

### 常用方法
- **Embedding相似度**：将用户请求和Skill Description都编码为向量，计算余弦相似度
- **关键词检索**：基于TF-IDF或BM25的文本匹配
- **混合检索**：Embedding + 关键词，取长补短

### 关键参数
- **召回数量K**：通常5-20个，太少可能漏掉正确Skill，太多增加重排负担
- **相似度阈值**：低于阈值的Skill直接过滤

## 重排阶段

### 常用方法
- **LLM直接判断**：将候选Skill的Description和用户请求一起送入LLM，让模型选择最合适的
- **打分排序**：让LLM对每个候选Skill打分，选最高分
- **Pairwise比较**：让LLM两两比较候选Skill，得出排序

## 与RAG的同构性

| 维度 | RAG | Skill路由 |
|------|-----|----------|
| 召回对象 | 文档片段 | Skill Description |
| 召回方法 | Embedding / 关键词 | Embedding / 关键词 |
| 重排方法 | LLM生成答案 | LLM选择Skill |
| 核心思想 | 先缩小范围，再精加工 | 先缩小范围，再精判断 |
