# Agent集群

## 定义

**Agent 集群**是由多个专业化 AI Agent 组成的协同工作架构，每个 Agent 负责不同的任务领域，通过协作完成复杂的量化分析工作。

## 架构组成

### 核心 Agent

| Agent | 职责 | 工作频率 |
|-------|------|----------|
| Analyst Agent | 研报分析、热门板块预测 | 每日 |
| 新闻 Agent | 主流媒体新闻扫描 | 每半小时 |
| 盘后分析 Agent | 大盘起势、板块、个股分析 | 收盘后 |

### 工作流程

```
新闻Agent(实时) → 早报Agent(早盘) → AnalystAgent(分析) → 盘后Agent(收盘)
```
