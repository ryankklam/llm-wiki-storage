# Agent长期记忆

## 定义

AI Agent 的长期记忆是指让智能体能够跨会话、跨时间地记住用户偏好、历史对话和领域知识的能力。它弥补了大语言模型本身无状态的缺陷，使 Agent 成为一个连续智能的伙伴。

## 关键信息

### 为什么需要长期记忆
1. **大语言模型无状态**：每次对话重新开始，无法记住上下文
2. **短期记忆有限**：Context Window 容量有限，无法容纳所有历史对话
3. **跨会话信息共享**：用户在不同会话间跳转时需要保持连续性
4. **学习用户习惯**：观察和学习用户使用习惯，提供智能反馈

### 记忆分层架构（三层）
1. **短期记忆**：对接大语言模型的 Context Window，速度快但容量小，存当前对话和中间推理结果
2. **会话记忆**：存入关系型数据库或 Redis，跨对话保持上下文连贯
3. **长期记忆**：用向量数据库或知识图谱存储用户偏好和事实性信息，长期影响 Agent 决策

### 核心流程
- **记录**：从短期记忆提取事实/偏好/经验 → 大语言模型语义理解 → Embedding 向量化 → 存入长期记忆
- **检索**：用户问题向量化 → 向量数据库 Semantic Search → 图数据库关联补全 → 注入短期记忆作为上下文

### 与 RAG 的区别
- **RAG**：从文档中提取知识，服务多用户/多任务
- **长期记忆**：聚焦单个用户/会话历史，个性化程度高

### 技术挑战
1. **准确性**：完善用户画像模型，兼顾更新与遗忘
2. **安全隐私**：防止隐私泄漏和数据重出攻击
3. **多模态**：文本/图像/语言记忆融合到统一空间
4. **记忆污染**：80% Agent 出错源于记忆污染

### 未来趋势
1. 记忆即服务（MaaS）
2. 强化学习引入记忆管理（RLHF）
3. 参数化记忆融合（Internal Memory）
4. 神经符号系统
5. 边缘计算部署
