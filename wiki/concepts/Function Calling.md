# Function Calling

## 定义

**Function Calling（函数调用）**是 LLM 调用外部函数的能力，是 Agent 基础能力层的重要组成部分。在 AI 编程项目中，rules.md / CLAUDE.md 可以约束 AI 如何、何时使用 Function Calling。

## 核心特征

### 与 rules.md 的关系
- Function Calling 的能力由模型提供
- 何时、如何调用由 rules.md 约束
- 工具使用规范应在项目规则中明确
