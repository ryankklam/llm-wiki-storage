# 阿里云长期记忆方案

## 定义

阿里云提供了四套 AI Agent 长期记忆的实践方案，覆盖从快速上线到深度推理的不同场景需求。

## 关键信息

### 四套方案对比

| 方案 | 定位 | 兼容性 | 知识图谱 | 检索方式 | 运维 | 适用场景 |
|------|------|--------|----------|----------|------|----------|
| 百练长期记忆 API | 托管服务 | 自有 API | 不支持 | 语义检索+预值过滤 | 平台托管 | 快速上线 |
| RDS PostgreSQL | 自建方案 | 兼容 Mem0 | Apache AGE | 向量+图混合检索 | 自维护 | Mem0 生态深度使用 |
| PolarDB Mem0 | SaaS 服务 | 兼容 Mem0 V1.0.1 | Graph Memory | 向量+图+Rerank | 平台托管 | 不想管运维 |
| PolarDB Agent Mem0 | 深度推理 | 自有 API | 实体/事件三元组 | 多路召回+图谱+Rerank | 自维护 | 复杂推理+高隐私 |

### 百练长期记忆 API
- 零部署，集成完善的用户画像体系
- 七大类用户信息：个人资料、兴趣爱好、生活习惯、健康状况等
- 支持多模态（图片描述、地理坐标）
- 支持 Java/Python SDK

### RDS PostgreSQL
- 全球最成熟的开源关系型数据库
- PGVector 支持向量检索
- Apache AGE 支持图数据库
- 三种存储方式集成在一个实例中
- 兼容 Mem0 SDK，免费

### PolarDB Mem0
- 云原生优化，100% 兼容 Mem0 V1.0.1
- 集成 Graph Memory，原生支持知识图谱
- 会话摘要和语义记忆两种策略
- 全面兼容通义千问模型（Qwen Plus、Text Embedding V4、Qwen Reward）
- 全托管按量付费

### PolarDB Agent Mem0
- 自研向量引擎，跑在 PolarDB for AI 节点上
- 向量+知识图谱双模存储
- 支持事件关系推理（时间推理、因果推理、假设推理）
- Working Memories 暂存区保证数据一致性
- 性能：检索速度提升 30%，Token 开销降低 20%，回答效果提升 40%
- 目前还在灰度阶段

### 选型建议
1. **已在用百练平台** → 百练长期记忆 API
2. **想深度使用 Mem0 生态 + 自主掌控数据** → RDS PostgreSQL
3. **最快上线 + 不想管运维** → PolarDB Mem0
4. **复杂推理 + 高数据隐私** → PolarDB Agent Memory
