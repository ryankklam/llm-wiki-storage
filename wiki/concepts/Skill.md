# Skill

## 定义

**Skill 是大模型2.0时代 Context 工程的标志性产物**，是完整的业务执行单元。它整合了大模型能力、外部工具、业务流程、数据接口，能创造出大模型本身不具备的闭环业务能力。

## 本质特征

### 与 Prompt 的核心区别

| 维度 | Skill | Prompt |
|------|-------|--------|
| 本质 | 完整的业务执行单元 | 大模型的单次指令输入 |
| 时代 | 大模型2.0时代 | 大模型1.0时代 |
| 工程 | Context工程 | Prompt工程 |
| 标准化 | 高度标准化 | 非标准化 |
| 可复用 | 高可复用 | 复用性极差 |
| 兜底能力 | 完整异常兜底 | 无兜底 |

### 核心灵魂

**渐进式上下文披露**：在正确的时机把正确的信息喂给大模型，把复杂任务拆分成多步，每一步只给模型当前需要的上下文。

## 技术架构

```
Skill = Context工程 + 工具 + 流程
```

- **Context工程**：渐进式披露上下文
- **工具整合**：外部工具、数据接口
- **流程编排**：业务流程标准化

## 关键信息
- Skill 的本质是一个文件夹，核心是 skill.md 文档（来源：[[2026-05-10-skill实战- 从0到1写一个你自己的skill]]）
- Prompt 只是 Skill 众多组成模块中的一个可选环节（来源：[[2026-05-11-万物都可蒸馏Skill-5min讲清机制]]）
- Skill 不是 Prompt 的套壳，而是大模型从"能聊天"走向"能干活"的核心载体
