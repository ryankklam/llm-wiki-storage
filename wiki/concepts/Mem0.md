# Mem0

## 定义

Mem0 是一个开源的 AI Agent 长期记忆框架，已成为很多开源项目的默认选择。它支持多层的记忆隔离，可以根据用户、智能体和运行实例来分层存储记忆。

## 关键信息

### 核心特点
- 支持多层的记忆隔离（用户/智能体/实例）
- 用 LLM 动态更新和清理记忆
- 支持多种数据库类型
- 兼容 Mem0 SDK

### 阿里云上的 Mem0 方案
1. **RDS PostgreSQL + Mem0 SDK**：自建方案，免费，支持向量+图混合检索
2. **PolarDB Mem0**：SaaS 服务，100% 兼容 Mem0 V1.0.1，全托管按量付费
3. **PolarDB Agent Mem0**：深度推理方案，自有 API，支持事件关系推理

### 与其他框架对比
| 框架 | 特点 | Token 优化 |
|------|------|------------|
| Mem0 | 多层记忆隔离，LLM 动态更新 | 支持多种数据库 |
| OpenViking | 记忆分三层（摘要/索引/全文） | 分层索引 |
| OpenClue | 文件优先，混合检索 | 向量+关键词融合 |
| Zap | 时间知识图谱 | 时间过滤 |
