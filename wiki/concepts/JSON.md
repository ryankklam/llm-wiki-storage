# JSON

## 定义

**JSON（JavaScript Object Notation）**是 AI 编程中常用的数据交换格式。在 rules.md / CLAUDE.md 规范中，可能需要约束 AI 生成 JSON 的格式、字段命名规范、数据结构等。

## 核心特征

### AI 生成 JSON 的规范要点
- **格式约束**：在 rules.md 中明确 JSON 的字段命名规范（camelCase / snake_case）
- **结构约束**：定义标准的数据结构模板
- **类型约束**：明确字段的数据类型要求
