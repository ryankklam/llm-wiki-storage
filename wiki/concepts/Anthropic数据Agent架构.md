# Anthropic 数据 Agent 架构

## 定义

**Anthropic 数据 Agent 架构是 Anthropic 内部用于自助业务分析的四层系统架构**，实现了 95% 场景的自助业务分析覆盖和 90% 的整体准确率。该架构将数据分析视为上下文和验证问题，而非单纯的 SQL 生成问题。

## 核心设计理念

Anthropic 没有让 Claude 直接在数仓里自由发挥，而是设计了一套被约束的工作路径：

> 先把地图画清楚，再规定路线，再给驾驶规则，最后检查有没有开错。

系统首先要对付三类失败：
1. **概念歧义**：同一个词有多个定义
2. **数据过期**：表结构、口径变化但说明没更新
3. **检索失败**：Agent 不知道该查哪里

## 四层架构

| 层级 | 名称 | 核心职责 | 类比 |
|------|------|----------|------|
| 第一层 | 数据基础 | 整理数据世界，收窄答案空间 | 画地图 |
| 第二层 | 可信来源 | 确定信息优先级和来源可信度 | 规定路线 |
| 第三层 | Skills | 编码资深分析师的工作流程 | 驾驶规则 |
| 第四层 | 验证 | 持续检查和纠错 | 复盘检查 |

## 关键数据

- 无 Skills 时准确率：最高不超过 21%
- 有 Skills 后准确率：稳定超过 95%，部分领域接近 99%
- 上线时离线准确率约 95%，一个月后若不维护会掉到约 65%
- 约 90% 的数据模型 PR 会同时包含 Skills 变更

## 核心结论

> 企业要做数据 Agent，不要一开始就对资料和权限。先画出你的答案路径，再让 Agent 沿这条路径工作。这比指望模型自己变聪明要可靠得多。

最小可行版本：少量官方数据集 + 基础语义层 + 离线评测 + 薄的 Knowledge Skill。
