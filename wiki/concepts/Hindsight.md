# Hindsight

> **类型**：开源 Agent 记忆系统
> **协议**：MIT
> **出品方**：Recurse（以 RAG 起家的公司）
> **定位**：让 Agent 随时间学习的记忆系统

## 定义

**Hindsight** 是一套开源的 Agent 长期记忆系统，核心目标不是"让 Agent 记住更多对话"，而是"让 Agent 从经历中学习，形成可复用的理解"。

## 核心设计

### 与传统方案的区别

| 方案 | 特点 | Hindsight 的改进 |
|------|------|-----------------|
| RAG | 向量检索，缺乏深度推理 | 加入跨记忆的反思推理 |
| 知识图谱 | 结构僵化 | 动态巩固、自动精炼 |

### 四类记忆结构（仿生数据结构）

1. **事实**（Facts）：客观知识，如"炉子会烫"
2. **经历**（Experiences）：自身体验，如"我碰了那炉子，真疼"
3. **观察**（Observations）：大量记忆巩固出的带证据信念，如"这炉子不能碰"
4. **心智模型**（Mental Models）：对世界的成见级理解，如"整个厨房的安全规则"

### 三个核心操作

- **Retain（存）**：LLM 提取事实、时间、实体关系，归一化后存入
- **Recall（取）**：四路并行检索（稠密向量 + BM25 + 图 + 时间），RRF 融合 + 交叉编码器重排
- **Reflect（想）**：对全库深度分析，生成观察和心智模型，新证据可精炼旧观察

### 特色机制

- **[[精制模型]]**：预生成问题的长备答案，一次数据库读取即可使用
- **[[知识业]]**：活文档式知识组织，像 Wiki 一样可检索、可导出 Markdown
- **库隔离**：每个库归一个用户/Agent/项目，严格隔离不串数据
- **性格参数**（Disposition）：影响 Reflect 时的推理口吻

## Benchmark 成绩

- 开源 20B 模型 + Hindsight：83.6 分（基线全量上下文仅 39 分）
- 论文称超过全量上下文的 GPT-4o
- 换更强骨干：LongMem 91.4 分，LoCoMo 89.61 分
- 此前最强开源记忆系统：75.78 分

## 适用场景

**适合**：既要对话又要自主干活的 Agent（如 AI 员工处理开放式任务）
**不适合**：简单工作流场景（Overkill）
