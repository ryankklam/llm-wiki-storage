# 立宪法

## 定义

**立宪法**是 Spec-Kit 框架的第一步核心命令，指在项目开始前创建一份 Constitution（项目宪法）文档，定义项目的核心原则、约束条件、开发流程和治理方式。在 Claude Code 中对应 CLAUDE.md，在 Cursor 中对应 rules.md。

## 核心特征

### 宪法内容

来源：[[2026-06-17-AI编程交付企业级项目SpecKit]]

1. **核心原则**：构建当前项目必须遵循的原则
2. **额外约束**：技术栈版本号、代码规范、禁止项
3. **开发流程**：项目开发的标准流程定义
4. **治理方式**：如何管理和维护项目

### 为什么需要立宪法

- AI 从零起步（Greenfield）时没有引导式提问，不知道自己漏了什么
- Constitution 是约束整个开发框架的"法律"
- 所有命令在运行时都必须遵循宪法的约束
- 无论是内置驱动、扩展插件还是 Preset 模板，都要遵循项目宪法

### 宪法质量决定输出质量

来源：[[2026-06-17-AI编程交付企业级项目SpecKit]]

Constitution 的质量直接决定 AI 在 Claude Code 驱动项目时的实际输出质量和必须遵循的规范。

## 关键信息

- Constitution 是写给 AI 的语言书，术语越精确、边界描述越清楚，AI 生成代码越规范（来源：[[2026-06-12-企业AI项目rules红线]]）
- 管 AI 跟管项目，本来就是同一件事（来源：[[2026-06-12-企业AI项目rules红线]]）
