# 代码规范

## 定义

**代码规范（Code Standards）**在 AI 编程时代有了新的内涵：不仅是人类开发者之间的约定，更是**写给 AI 的约束语言**。通过 rules.md / CLAUDE.md 等文件，向 AI Agent 明确代码风格、复用策略、目录结构和技术边界。

## 核心特征

### AI 时代的代码规范特点
- **读者是 AI**：术语要精准，边界要清晰
- **禁止项优先**：告诉 AI 不能做什么比能做什么更有效
- **量化可验证**：避免"代码要优雅"这类模糊描述
- **附原因**：AI 知道为什么才会真正遵循

### 核心组成

来源：[[2026-06-12-企业AI项目rules红线]]

1. **技术栈约束**
   - 写具体版本号（如 React 19、Tailwind CSS v4）
   - 禁止引入不必要的框架

2. **代码复用策略**
   - 同一 UI 模式不能出现两次，必须抽象成组件
   - 生成代码前先检查现有代码能否复用
   - AI 天然倾向新建代码，必须明确约束

3. **目录与文件规范**
   - 统一的目录结构
   - 一个组件一个文件
   - 长期模板统一放置

4. **质量约束**
   - TypeScript 原则
   - API 接口规范
   - 环境变量管理（如 API Key）

## 关键信息

- AI（无论是 Claude 还是 Codex）更喜欢新建代码而不是复用现有代码，这是它们一直以来存在的问题（来源：[[2026-06-12-企业AI项目rules红线]]）
- 代码规范不是写给人看的，是写给 AI 在执行代码时看的约束
- 好的规范让 AI 生成代码以及维护后续项目的过程中越来越规范
