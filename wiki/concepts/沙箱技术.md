# 沙箱技术

> **领域**：系统安全 / 云计算

## 定义

**沙箱**（Sandbox）是一种安全机制，让不可信代码运行，但限制它所能造成的破坏。

> 核心目标不是阻止代码运行，而是限制**[[爆炸半径]]**。

## 威胁模型

| 场景 | 威胁 |
|------|------|
| 云厂商 | 防别的租户 |
| 浏览器 | 防恶意网页 |
| Serverless | 防函数逃逸 |
| AI Agent | 防模型自生成代码被提示词注入操控 |

## 三个核心概念

1. **隔离**：让 A 看不到 B
2. **资源限制**：让 A 用不光资源
3. **权限控制**：让 A 做不了某些操作

> ⚠️ 常见误区：Cgroups 只做资源限制，不是隔离边界。

## 技术光谱

沙箱技术的核心是在**隔离强度、性能密度、兼容性**三角中寻找平衡：

1. **[[容器隔离]]** - 共享宿主内核，轻量但存在内核漏洞风险
2. **[[gVisor]]** - 用户态假内核，强隔离但兼容性差
3. **[[MicroVM]]** - 独立 guest 内核，硬件级隔离且轻量
4. **独立主机** - 物理隔离，最安全但最重

## 关键机制

- **Namespaces**：改变进程视野
- **Cgroups**：限制资源使用
- **Capabilities**：切碎 root 权限
- **[[Seccomp]]**：过滤系统调用（白名单优于黑名单）
- **LSM**（AppArmor/SELinux）：强制访问控制
