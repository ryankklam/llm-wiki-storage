# 渐进式上下文披露

## 定义

**渐进式上下文披露是 Context 工程的核心灵魂**，指在正确的时机把正确的信息喂给大模型，把复杂任务拆分成多步，每一步只给模型当前需要的上下文。

## 核心原则

1. **不追求一次性告诉模型所有事**
2. **把复杂任务拆分成多步**
3. **每一步只给当前需要的上下文**
4. **逐步引导模型完成任务**

## 实践案例：会议纪要整理

### 传统 Prompt 做法
- 把一万字录音转写 + 整理要求 + 待办格式 + 输出规范一次性塞给大模型
- 问题：上下文太长挤占窗口、关键信息被淹没、大模型容易走神、准确率下降

### 渐进式披露做法
- 把任务拆分成四个独立步骤
- 每一步只处理当前任务的少量上下文
- 结果：准确率提升、Token消耗降低、可单独修正
