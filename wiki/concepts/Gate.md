# Gate（门控）

## 定义

**Gate（门控）** 是 Spec-Kit 框架中的核心设计机制，指在每个步骤完成后设置人工检查点，AI 必须停下来等待人工确认后才能推进到下一步。这是 Spec-Kit 与轻量工具（如 OpenSpec）最本质的区别。

## 核心特征

### 工作原理

来源：[[2026-06-17-AI编程交付企业级项目SpecKit]]

- Spec-Kit 在每一步完成后都会停下来，由人工进行确认
- 每个环节多次停下来向用户询问：我要不要干这件事情？做这件事情可不可以？
- 内部有很多 Gate，到了门控点就会停下来提问或确认

### 与轻量工具的核心区别

- **轻量工具**：一口气替你跑完，回头乱成一锅粥
- **Spec-Kit**：每一步都停下来等你点头，步步看得见

### 设计理念

来源：[[2026-06-17-AI编程交付企业级项目SpecKit]]

- Claude Code 本身是黑盒
- Spec-Kit 通过文档驱动项目的整个进度
- 中间的 Spec 需要人类来掌控，才能很好地掌控整个项目的开发进度
- 比较推崇每一步的产出需要经过人工确认后再推进

## 关键信息

- Gate 门控机制是 Spec-Kit 与 OpenSpec 最大的区别（来源：[[2026-06-17-AI编程交付企业级项目SpecKit]]）
- 让 AI 停下来等你点头，比让 AI 跑得快更重要（来源：[[2026-06-17-AI编程交付企业级项目SpecKit]]）
