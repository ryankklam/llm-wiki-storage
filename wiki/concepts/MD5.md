# MD5

## 定义

MD5（Message-Digest Algorithm 5）是一种广泛使用的密码学哈希函数，由Ron Rivest于1991年设计。它能将任意长度的输入转换为128位（16字节）的固定长度哈希值，通常表示为32位十六进制字符串。

## 关键特性

| 特性 | 说明 |
|------|------|
| 输出长度 | 固定128位 |
| 单向性 | 不可逆，无法从哈希值还原原始数据 |
| 速度 | 计算极快 |
| 碰撞抗性 | 已被证明存在碰撞漏洞，不安全 |

## 为什么不能用于密码存储

1. **算得太快**：攻击者每秒可计算几亿次MD5哈希，暴力破解成本极低（来源：[[2026-07-03-面试问密码怎么存答MD5直接被淘汰]]）
2. **彩虹表威胁**：海量常见密码的MD5值已被预先计算并制成彩虹表，泄露后可直接查表秒级还原（来源：[[2026-07-03-面试问密码怎么存答MD5直接被淘汰]]）
3. **无内置盐机制**：相同密码始终产生相同哈希，便于批量攻击（来源：[[2026-07-03-面试问密码怎么存答MD5直接被淘汰]]）
4. **已存在碰撞**：MD5的碰撞漏洞使其在密码学场景中已被淘汰

## 常见误区

- **"MD5加密"**：MD5不是加密，是哈希。加密是可逆的，哈希是单向的。（来源：[[2026-07-03-面试问密码怎么存答MD5直接被淘汰]]）
- **"MD5+盐就安全了"**：加盐能解决彩虹表问题，但MD5算得快的根本缺陷仍在，无法抵御高速暴力破解。（来源：[[2026-07-03-面试问密码怎么存答MD5直接被淘汰]]）

## 现状

MD5在今天基本等于明文存储密码。这是十几年前就该淘汰的做法。（来源：[[2026-07-03-面试问密码怎么存答MD5直接被淘汰]]）
