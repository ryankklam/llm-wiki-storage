# Agentic Loop

> Agent 自主运行的核心循环机制，强调 Agent 的自主性和自驱性。

## 定义

Agentic Loop（Agent 循环）是 Agent Loop 的另一种表述，更强调 Agent 的自主性（Agentic）特征。它描述 Agent 在最小人工干预下，通过循环迭代自主完成任务的机制。

## 核心特征

- **自主性**：Agent 在循环中自主决策，无需人工干预
- **自驱性**：循环由 Agent 自身驱动，而非外部触发
- **迭代性**：通过反复迭代逐步逼近目标
- **反馈驱动**：每一轮的输出成为下一轮的输入

## 与 Agent Loop 的关系

Agentic Loop 与 Agent Loop 本质上是同一概念的不同表述。Agentic Loop 更强调"自主性"这一维度，而 Agent Loop 是更通用的表述。
