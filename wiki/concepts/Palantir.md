# Palantir

## 定义

**Palantir** 是一家大数据分析公司，核心产品 Foundry 基于 Ontology 构建企业数字孪生平台。

## 核心产品

| 产品 | 说明 |
|------|------|
| Foundry | 企业数据平台，基于 Ontology |
| Gotham | 政府/国防数据分析平台 |
| AIP | AI 平台，集成 LLM 与 Ontology |

## 护城河

> Palantir 的护城河不是算法，而是 Ontology——把任何行业的数据都能映射成对象模型的能力。

关键能力：
- 跨行业 Ontology 模板
- OSDK（Ontology SDK）开发工具
- 数字孪生快速构建
