# 兜底能力

## 定义

**兜底能力是 Skill 的核心稳定性保障**，指 Skill 具备的完整异常处理机制，确保在各种异常情况下都能给出明确的反馈，不会直接崩溃。

## 与 Prompt 的对比

| 维度 | Skill | Prompt |
|------|-------|--------|
| 兜底能力 | 完整异常兜底 | 无兜底 |
| 容错率 | 高 | 0 |
| 稳定性 | 可控 | 不可控 |

## 具体机制

1. **严格的参数校验**：入参必须符合规范
2. **重试机制**：接口调用失败自动重试
3. **分段处理**：文本太长自动分段
4. **内容拦截**：内容违规自动拦截
5. **错误提示**：极端情况给出明确的错误提示和解决方案

## 关键信息
- 标准化的 Skill 都有严格的参数校验、重试机制、异常兜底逻辑（来源：[[2026-05-11-万物都可蒸馏Skill-5min讲清机制]]）
