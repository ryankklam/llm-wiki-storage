# 摘要压缩

## 定义

**摘要压缩（Summarization/Compression）** 是将长内容压缩为关键信息的策略，用于在有限的上下文窗口中保留最重要的信息。

## 核心方法

### 1. 历史对话压缩

把一大段历史压成：
- 任务状态
- 关键决定
- 待办事项
- 风险点

### 2. 重要事实抽取

抽取关键信息：
- 接口名
- 文件路径
- 用户明确约束
- 已验证过的结论

### 3. 工具结果处理

将大段内容变成结构化摘要：
- 大段日志 → 关键错误/状态
- 大段网页 → 核心信息点
- 大段检索结果 → 相关片段

## 风险与应对

### 风险：摘要丢信息

**解决方案**：摘要旁边要保留可回溯的事实抽取和原始来源。

### 最佳实践

```
[摘要]
├── 核心结论
├── 关键约束
├── 待办事项
└── 来源指针 → 可回查原文
```

## 在上下文优先级中的位置

摘要压缩后的内容优先级：
1. 系统规则（最高）
2. 当前请求
3. 高相关证据
4. **压缩后的历史摘要**
5. 长期偏好摘要
