# 知识业

> **英文**：Knowledge Business
> **来源**：Hindsight 记忆系统

## 定义

**知识业**是 Hindsight 中[[精制模型]]的进一步封装。给一个名字和一个问题，剩下全用默认值，知识库会自动把自己写成活文档。

## 核心特点

1. **活文档**：知识库像 Wiki 一样组织，内容随记忆自动更新
2. **可检索**：文档内容可被检索系统索引
3. **可导出**：可导出成 Markdown 文件
4. **默认值驱动**：只需提供名字和问题，其他配置自动化

## 应用方式

- 给 Agent 配长期项目记忆：每个仓库一个库，从 Git 历史和过往对话自动建立
- Agent 开工时直接注入文档内容，再配一页页的知识页写清架构约定和正在进行的工作

## 与其他概念的关系

- 是 [[精制模型]] 的封装形式
- 类似 [[Wiki]] 的活文档组织方式
- 与 [[按需知识树]] 理念相通——都是按需组织的知识结构
