# Chain of Thought

## 定义

**Chain of Thought（思维链，简称 CoT）是一种 Prompt 技术技巧**，通过引导模型逐步展示推理过程，提高复杂问题的解决质量。Extended Thinking 是 Anthropic 对这一技术的实现。

## 核心原理

### 传统方式 vs 思维链

**传统方式**：直接给出答案
```
问题：如果我升级到 30GB 套餐，我的下一份账单是多少？
答案：你的下一份账单是 XXX 元。
```

**思维链方式**：展示推理过程
```
问题：如果我升级到 30GB 套餐，我的下一份账单是多少？
推理：
1. 当前日期是 5 月 15 日，月费周期从 1 号开始
2. 当前套餐是 20GB，月费 100 元
3. 新套餐是 30GB，月费 150 元
4. 剩余天数：16 天 / 31 天 = 51.6%
5. 当前套餐剩余价值：100 × 51.6% = 51.6 元
6. 新套餐按比例费用：150 × 51.6% = 77.4 元
7. 差价：77.4 - 51.6 = 25.8 元
答案：你的下一份账单将增加 25.8 元。
```

## Extended Thinking

Anthropic 的 Extended Thinking 功能让模型可以：
- 自己决定需要多少推理
- 自适应地分配思考资源
- 更可靠地解决复杂问题

### 使用方式

通过 API 参数启用，无需修改 Prompt：
```python
response = client.messages.create(
    model="claude-opus-4-7",
    thinking={"type": "enabled", "budget_tokens": 10000},
    messages=[...]
)
```

## 性能对比

### 员工排班表示例

| 方案 | 结果 | Tokens | 延迟 |
|------|------|--------|------|
| Sonnet 4.6 + 简单 Prompt | 全部失败 | 高 | 低 |
| Opus 4.7 + Extended Thinking | 全部通过 | 很高（3x） | 很高（3x） |

### 适用场景

- 复杂推理任务
- 需要高可靠性
- 可以接受较高的延迟和成本

## 与其他方案对比

| 方案 | 复杂度 | 可靠性 | 成本 | 延迟 |
|------|--------|--------|------|------|
| 简单 Prompt | 低 | 低 | 低 | 低 |
| Extended Thinking | 低 | 高 | 高 | 高 |
| 生成-评估-修复循环 | 中 | 高 | 低 | 低 |

## 最佳实践

1. **选择合适的场景**：复杂推理任务才需要
2. **权衡成本**：Extended Thinking 会显著增加 tokens 和延迟
3. **考虑替代方案**：生成-评估-修复循环可能更高效
4. **配合工具使用**：对于计算类任务，给模型工具比让它做心算更可靠
