# 消融实验

## 定义

**消融实验（Ablation Experiment）是评估系统组件价值的实验方法**，每次只拿掉一个组件，用固定评测集对比通过率，一小时内能替代大量争论。

## 核心方法

1. 每次只改一个组件
2. 用固定评测集对比通过率
3. 如果拿掉以后准确率没变 → 组件可能没那么值
4. 如果拿掉以后准确率掉很多 → 值得保留

## Anthropic 最有价值的发现：负结果

最有价值的一次消融反而是负结果：直接给 Agent 整个看板、转换模型、基本 SQL 全文，确认它确实读了，但准确率变化不到一个百分点。

进一步检查发现 80% 的错误题答案就在语料里，Agent 还是没有用。

### 核心结论

> 评价不再更多信息，而在信息有没有被结构化地编排。

这个实验把路线图重新定向了好几个月。

## 实践建议

- 靠消融实验判断是不是应该给 Agent 更多资料
- 固定一套评测，只改一个变量，跑前后对比
- 如果没有提升，哪怕想法听起来很合理，也不要继续加复杂度
- 试过没用的办法也要记录下来
