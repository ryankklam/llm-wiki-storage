# Cursor

## 定义

**Cursor**是 AI 编程编辑器，支持通过 Cursor Rules（.cursorrules）文件进行项目级规则约束。功能上与 Claude Code 的 CLAUDE.md、通用 rules.md 本质相同。

## 关键信息

- Cursor 的 Cursor Rules 本质与 rules.md、CLAUDE.md 相同，都是立给 AI 的项目规则文件（来源：[[2026-06-12-企业AI项目rules红线]]）
- 是 Coding Agent 的代表产品之一
