# AI Agent 沙箱

> **领域**：AI 安全 / Agent 工程

## 定义

**AI Agent 沙箱**是专门为 AI Agent 执行代码设计的安全沙箱。与传统沙箱不同，Agent 执行的是模型运行时才生成的代码，无法预先审计。

## 核心挑战

传统的代码审计 + 签名的供应链思路**全部失效**。

## 三个新约束

### 1. 有状态任务
- 要能暂停、恢复
- 文件系统要持久化

### 2. 凭证隔离
- 凭证必须**物理上不可达**
- 不能赌模型拿受限 token 做不到坏事
- 因为模型能力一直在涨，这个假设总会过期

### 3. 网络出口控制
- 既要能装依赖，又要防外泄——天然矛盾

## 真实事故：Anthropic 数据外泄

出口白名单放行了自家 API 域名，攻击者用自己的 key 把工作区文件传到了自己的账户。

> 沙箱完美工作，数据照样外泄。

## 核心教训

分析不是"目标过滤器"，而是"能力授予"。
- 不要问："这个域名可不可信？"
- 要问："这个域名上暴露了哪些功能？"
