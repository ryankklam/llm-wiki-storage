# 短期记忆管理

## 定义

短期记忆只服务**当前会话**，重点是让模型记住最近发生了什么。

## 核心策略

### 1. 滑动窗口（Sliding Window）

最直接的方法：保留最近几轮对话，太早的内容先移出去。

**局限**：有些早期约束很关键，比如用户说"不要改数据结构"。

### 2. 摘要压缩（Summarization/Compression）

把一大段历史压成：
- 任务状态
- 关键决定
- 待办
- 风险

### 3. 重要事实抽取

更稳一点的做法，抽取：
- 接口名
- 文件路径
- 用户明确约束
- 已验证过的结论

### 4. 工具结果处理

大段日志、网页、检索结果，先变成结构化摘要，再放进上下文。

## 最佳实践

| 场景 | 策略 |
|------|------|
| 对话历史 | 滑动窗口 + 摘要压缩 |
| 关键约束 | 事实抽取，单独保留 |
| 工具结果 | 结构化摘要 |
| 已验证结论 | 事实表形式 |

## 面试追问

**摘要丢信息怎么办？**

摘要旁边要保留可回溯的事实抽取和原始来源。
