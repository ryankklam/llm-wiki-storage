## 核心发现

### Skill vs Prompt 的本质区别
> **Skill的本质绝对不是Prompt**，Skill是大模型从 Prompt 工程时代进入 Context 工程时代的标志性产物。

**三大本质区别**：
1. **底层定位**：Prompt 是单次指令输入，Skill 是完整业务执行单元
2. **标准化程度**：Prompt 非标准化，Skill 高度标准化
3. **兜底能力**：Prompt 无兜底，Skill 有完整异常处理

### 核心技术演进
- **大模型1.0时代**：Prompt工程 → 一次性告诉模型所有事
- **大模型2.0时代**：Context工程 → 在正确时机给正确信息

**渐进式上下文披露**是 Context 工程的核心灵魂，也是 Skill 的核心灵魂。
