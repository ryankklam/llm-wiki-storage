### Agent分类体系
Agent按产出类型可分为两大类：
1. **Coding Agent**（Claude Code、Codex、OpenCode）：产出代码，预装完整工具链
2. **日常任务Agent**（Pi Agent）：产出结果，极简底座 + Skill按需扩展

### Pi Agent的核心优势
- System Prompt不到1500 tokens（Claude Code约20000 tokens）
- 三大优势：快、省（token消耗约1%）、聪明（注意力集中）
- 核心公式：Agent + Skill = 最基本的框架

### Skill生态
- Skill是给Agent的说明书/操作手册
- 按需安装，支持global和project两种模式
- 覆盖搜索、文件读取、语音合成、图片生成、视频制作等场景

### 工具协议
- **MCP (Model Context Protocol)**：标准化工具接口协议
- **Function Calling**：大模型原生工具调用能力
- **Claude Code**：同时支持 Bash 工具和 MCP 工具

### AI Agent 长期记忆（阿里云选型指南）

#### 记忆分层架构
1. **短期记忆**：对接大语言模型的 Context Window，速度快但容量小
2. **会话记忆**：存入关系型数据库或 Redis，跨对话保持上下文连贯
3. **长期记忆**：用向量数据库或知识图谱存储用户偏好和事实性信息

#### 长期记忆 vs RAG
- **RAG**：从文档中提取知识，服务多用户/多任务
- **长期记忆**：聚焦单个用户/会话历史，个性化程度高

#### 主流存储方案
| 方案 | 优点 | 缺点 |
|------|------|------|
| 向量数据库 | 语义检索，表述不同也能匹配 | 实体关系表达能力弱 |
| 知识图谱 | 擅长复杂关系查询 | 构建和维护成本高 |
| Markdown 文件 | 透明、方便版本控制和审计 | 检索能力有限 |

#### 主流框架
- **Mem0**：多层记忆隔离，LLM 动态更新，已成为开源默认选择
- **OpenViking**：记忆分三层（摘要/索引/全文），分层索引优化 Token
- **OpenClue**：文件优先，向量+关键词混合检索
- **Zap**：时间知识图谱，双时间戳处理时效性

#### 阿里云四套方案
1. **百练长期记忆 API**：零部署托管服务，集成用户画像体系
2. **RDS PostgreSQL**：自建方案，PGVector + Apache AGE，兼容 Mem0 SDK
3. **PolarDB Mem0**：SaaS 服务，全托管按量付费，兼容 Mem0 V1.0.1
4. **PolarDB Agent Mem0**：深度推理，向量+知识图谱双模存储，支持事件关系推理

#### 技术挑战
- 准确性：完善用户画像模型，兼顾更新与遗忘
- 安全隐私：防止隐私泄漏和数据重出攻击
- 多模态：文本/图像/语言记忆融合
- 记忆污染：80% Agent 出错源于记忆污染

#### 未来趋势
1. 记忆即服务（MaaS）
2. 强化学习引入记忆管理（RLHF）
3. 参数化记忆融合（Internal Memory）
4. 神经符号系统
