## 视频内容摘要

Agent是AI应用现在最重要的领域。视频将Agent分为两类：
1. **Coding Agent**（如Claude Code、Codex、OpenCode）：产出是代码，内置完整的写代码流程和工具
2. **日常任务Agent**（如Pi Agent）：产出是结果，代码只是中间手段

Pi Agent采用极简主义设计，底座只保留4个工具：读文件、写文件、改文件、跑命令。能力通过Skill按需安装。Pi Agent的system prompt不到1500 tokens，比Claude Code少十几倍，带来三大优势：快（上下文短）、省（token消耗低，约为Claude Code的1%）、聪明（注意力集中）。

视频演示了安装和配置Pi Agent的完整流程（基于Node.js和PieWeb），以及安装5个Skill的过程：
1. **搜索Skill**：Tavily Search（免费1000次/月）和Brave Search
2. **PDF Skill**：读取文字版和扫描版PDF
3. **Office Skill**：Word、PPT、Excel
4. **TTS Skill**：语音合成，无需账号
5. **生图Skill**：调用GPT-4o生成图片
6. **HyperFrames Skill**：生成带动画的HTML网页，可渲染为视频

最后以英伟达GB200 NVL72 AI机柜成本调研报告为实战案例，展示了Agent + Skill工作流的完整能力：从一句话开始，交付一份包含资料笔记、成本拆解、演讲稿、语音、图片素材和HyperFrames演讲页面的完整调研报告。

核心公式：**Agent + Skill = 最基本的框架**
