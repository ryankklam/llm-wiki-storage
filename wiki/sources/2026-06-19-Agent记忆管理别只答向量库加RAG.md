# Agent记忆管理：别只答向量库加RAG

> 面试被问到"Agent怎么做记忆管理"，只答"向量数据库+RAG"说明缺乏真实生产经验。向量库在精确查找和时间状态管理上存在天然劣势。真正的生产级Agent记忆是一套包含分层设计、显式读写策略、时间状态管理和程序性经验沉淀的完整系统。本期视频为你深度拆解生产级Agent记忆架构，带你了解状态管理三件套与双时间机制。

## 核心观点

1. **向量数据库+RAG只是基础，不是答案**：面试只答向量库加RAG，面试官会判定你没有真实生产经验
2. **向量数据库有两大致命局限**：模糊匹配 vs 精确查找的冲突；时间状态盲区（新旧状态同时存在导致决策错误）
3. **生产级记忆是四层分层架构**：会话元数据 → 结构化用户档案 → 近期对话摘要 → 滑动窗口
4. **状态管理三件套**：Ledger（原始账本）+ View（派生视图）+ Policy（控制策略）
5. **双时间机制解决时间盲区**：Valid Time（现实有效时间）+ Transaction Time（系统写入时间）
6. **程序性经验沉淀**：把高频成功路径固化为可复用的Skill，让Agent越用越聪明
