## 视频内容摘要

这是 Anthropic 技术团队成员 Boris 在 Code with Claude 会议上的演讲，分享了 Claude Code 的实用技巧和最佳实践。

### Claude Code 简介

Claude Code 是 Anthropic 推出的新一代 AI 编程助手，与之前的代码补全工具不同，它是完全 Agentic 的：
- 可以编写完整功能、整个文件、修复整个 Bug
- 兼容所有 IDE（VS Code、Xcode、JetBrains 等）
- 支持本地、SSH、Tmux 等各种环境

### 入门建议

**从代码库问答 (Codebase Q&A) 开始**
- Anthropic 新员工培训的第一步
-  onboarding 时间从 2-3 周缩短到 2-3 天
- 无需索引，代码完全本地，不上传云端

### 核心技巧

#### 1. 规划优先
- 大功能实现前，先让 Claude 头脑风暴、制定计划
- 确认后再编写代码，避免返工

#### 2. 工具集成
- **Bash 工具**：告诉 Claude 团队 CLI 工具的使用方法
- **MCP (Model Context Protocol)**：标准化工具接口

#### 3. 反馈循环
- 提供测试、截图等反馈工具让 Claude 自我迭代
- 2-3 次迭代后结果几乎完美

#### 4. Claude.md
- 项目根目录的特殊文件，存储上下文
- 包含：常用命令、架构决策、重要文件、MCP 工具配置

### 快捷键与技巧

- **Shift+Tab**：自动接受编辑
- **# + 内容**：让 Claude 记住某事（自动写入 Claude.md）
- **! + 命令**：执行 Bash 命令并进入上下文
- **Esc**：安全停止当前操作
- **Esc x2**：跳回历史
- **Ctrl+R**：查看完整输出
- **`--resume` / `--continue`**：恢复会话

### SDK 使用

`claude -p` 将 Claude 作为 Unix 工具使用：
- 支持 JSON / 流式 JSON 输出
- 可管道输入输出（配合 `git status`、`jq` 等）
- 适用于 CI、事件响应、数据处理管道

### 高级用法

- **多模态**：支持图片输入（拖拽、文件路径、复制粘贴）
- **并行会话**：通过 SSH、Tmux、Git worktrees 运行多个 Claude 会话

### Q&A 精华

1. **最难实现的部分**：Bash 命令的安全性 - 平衡安全性与生产力
2. **为什么选择 CLI 而非 IDE**：终端是最大公约数；预见 IDE 可能被淘汰
3. **内部使用情况**：80% Anthropic 技术人员每天使用 Claude Code
