# Agent成本优化：如何让同样的任务少花钱

> Agent行业正在经历从拼能力到算成本的换代。Cursor Router用60多万条真实请求训练路由器，在保持效果的情况下最多节省60%成本。模型路由不是简单任务走便宜模型、复杂任务走贵模型，而是一个涉及硬性约束过滤、真实收益预测、动态升级、验证反馈和持续学习的小型调度系统。核心优化目标不是每个Token有多便宜，而是每一块钱能换回多少被接受的结果。

## 核心观点

1. **行业正在换代**：从粗放投入转向精细化资源调度，关注点从使用率转向单位产出和投入产出比
2. **成本口径要算对**：不是单次调用成本，而是每个成功任务从提出到合并的总成本，包括推理、缓存、重试、验证和人工返工
3. **缓存比单价更重要**：IBM Research案例显示，Claude Sonnet凭借缓存优势，总成本反而比单价更低的GPT-4.1低一半
4. **模型路由是专长调度**：不同模型在不同任务维度上各有优势，Opus、Gemini、Qwen Max、Kimi K2.5在不同场景下分别最优
5. **路由器缺的是信息不是智商**：给路由模型补充历史真实表现数据，成绩可提升15.3%
6. **五层架构**：硬性约束过滤 -> 预测真实收益 -> 执行验证和动态升级 -> 验证器 -> 记忆和持续学习
7. **成本调度有三层**：模型路由（谁来思考）+ 上下文路由（看到什么）+ 工具路由（开放哪些能力）
8. **四个坑**：成本质量粗暴合并、只用历史平均值、只看每次请求成本、完全停止探索
9. **最小可行版本四步法**：统一记录成本 -> 规则分档 -> 验证升级机制 -> 训练轻量分类器

## 视频章节

### 一、行业背景：从拼能力到算成本
- [00:00] Agent行业正在经历非常现实的换代，从拼模型能力转向算成本
- [00:34] 真正大规模使用Agent的公司开始收紧预算、核算AI支出
- [01:03] 成本优化从财务问题变成Agent工程本身的问题
- [01:34] 关注点不是少用Agent，而是让同样任务少花冤枉钱

### 二、成本的本质：每个成功任务的真实成本
- [01:40] Agent能力越强，Loop每增加一轮，历史上下文、工具定义、缓存、读写和推理开销都跟着累积
- [02:04] 真正值得优化的是一个需求从提出到合并的总成本，即每个成功任务的成本

### 三、Cursor Router：从单次调用到每次提交
- [02:14] Cursor发布Cursor Router，自动为每个编码请求选择模型
- [02:37] 用60多万条请求训练，数百万条线上AB测试，最多节省60%成本
- [02:59] 竞争指标从单次回答质量转向每个有效产出的成本

### 四、模型路由不是简单的强弱分流
- [03:35] IBM Research案例：GPT-4.1单价更低，但因缓存劣势总成本是Sonnet的两倍
- [04:31] Agent Router测试8个前沿模型，9个维度里5个不同模型分别最优
- [05:02] 路由模型补充历史表现数据后成绩提升15.3%，缺的是信息不是智商
- [05:41] Agent任务真实成本包括：首次推理、缓存读写、推理Token、失败重试、缓存失效、结果验证、人工返工

### 五、降级的期望成本计算
- [05:58] 便宜模型期望成本 = 单次成本 + 失败概率 × 强模型成本
- [06:26] 先用便宜模型试再升级并不天然省钱，临界失败率远低于直觉预期

### 六、能落地的模型路由五层架构
- [06:37] 第一层：硬性约束过滤（合规、区域、上下文长度、工具协议等）
- [06:59] 第二层：预测真实收益（仓库语言、文件数量、任务阶段、历史失败次数、缓存状态）
- [07:40] 第三层：执行验证和动态升级（按阶段路由，保持模型粘性）
- [08:38] 第四层：验证器（编译、单测、静态分析、用户保留率）
- [09:19] 第五层：记忆和持续学习（记录任务特征、Token消耗、验证结果，写回记忆）

### 七、成本调度的三层结构
- [09:52] 模型路由省下的钱可能被臃肿的Harness吃回去
- [10:19] 完整成本调度 = 模型路由 + 上下文路由 + 工具路由

### 八、模型路由的本质
- [10:38] 不是分类问题，而是小型调度系统，像操作系统调度CPU

### 九、四个常见坑
- [11:01] 坑一：成本和质量粗暴压成一个固定分数
- [11:24] 坑二：只用历史平均值，不按任务类型和团队切分
- [11:41] 坑三：只看每次请求成本，不看每个通过验收的任务成本
- [12:02] 坑四：完全停止探索，新模型永远拿不到流量

### 十、最小可行版本四步法
- [12:27] 第一步：统一记录每个任务的完整成本和最终结果
- [12:34] 第二步：用规则做两到三个档位
- [12:48] 第三步：加验证和升级机制
- [12:58] 第四步：用真实数据训练轻量分类器，线上对照实验验证

### 十一、总结
- [13:13] Cursor Router的意义是把成本优化问题摆到台面上
- [13:47] 模型路由优化的不是每个Token有多便宜，而是每一块钱能换回多少被接受的结果
- [13:53] 成熟的Agent系统是知道哪一步值得使用多少智能，并且能用真实结果证明
