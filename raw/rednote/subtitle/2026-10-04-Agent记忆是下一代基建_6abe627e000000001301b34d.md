# Agent 记忆是下一代基建？——拆解 Hindsight 学习式记忆设计

## Whisper 转录原文

今天讲一个昨天冲上 getup 榜单第二的项目，一天拿了差不多 4500 个 star。它叫 Hindsight，Recurse 公司出品，开源 MIT 协议。这家公司有意思，自己就是做 RAG 起家的，等于做 RAG 的人亲手承认 RAG 不够。

官方定义一句话：一套让 Agent 随时间学习的记忆系统，目标是让 Agent 变聪明。

开篇先把同行划了个界：市面上的大多数 Agent 记忆系统力气花在回忆对话历史上，Hindsight 关心的是让 Agent 学习，而不只是记住。它对标的两类旧方案是 RAG 和知识图谱，官方说法是这两类都有短板，而它在长期记忆基准上跑出了最好的成绩。

先看记忆怎么组织。按它的说法，大多数记忆实现用的就是基础向量检索，好一点的加个知识图谱。它自己换成了仿生数据结构，照着人类记忆的类型来组织：
- 事实：炉子会烫，这样的客观知识
- 经历：我碰了那炉子，真疼，这种自己的体验
- 观察：大量记忆巩固出来的带证据的信念，碰了一回又一回，回回都疼，这些经历长成一条判断：这炉子不能碰
- 心智模型：从观察和事实里合成的对世界的成见级理解，从炉子到整个厨房，哪儿能碰、什么时候得小心，心里有了谱

记忆放在库里，一进来先进事实或经历其中一条通路，然后表示成实体、关系和时间序列，配上稀疏向量加稠密向量两组索引，方便日后取用。

结构上就三个动作：Retain, Recall, Reflect，中文可以叫存、取、想。

存（Retain）：原文势力就一行代码，把 Alice 设为资深工程师了。Retain 进一个库，你给一句人话，后台的 LLM 把关键事实、时间、实体关系抽出来，归一化变成规范的实体、时间序列和稀疏索引，挂进上面那几张网络。一句话，库里长出的是结构。

取（Recall）：查 Alice 干什么的，它并行跑四路：
1. 稠密向量那路走向量相似度
2. 关键词那路走 BM25 精确匹配
3. 图那路顺着实体、时间、因果关系找
4. 时间那路按时间范围过滤

四路结果合并，用倒数排名融合（RRF）排序，再过一个交叉编码器（Cross-Encoder）重排——把问题和候选片段一起读一遍再打分的模型，最后按 Token 上限裁掉。

想（Reflect）：这个动作 RAG 体系里没有。原文给了三个场景：
- AI 项目经理问：这个项目有什么风险要处理？
- 销售：哪种外联消息有人回？
- 客服：想一想哪些用户问题文档答不上？

这三个问题的答案都不在任何单条记忆里。Reflect 对整个库做更深的分析，得出结论，反过来在库里建立新的连接。传进来的事实不会停留成一堆平铺的碎片，后台把相关记忆巩固成观察。一条观察是一个去重过、带证据的信念，背后留着原文引文、带着证明。新证据到来时，旧的观察被精炼，不覆盖。原文给了三个词：强化、弱化、延伸。上一节四类记忆里的观察就是这么长出来的。

再往上是精制模型（Refined Model）。原文定义就一句：对某个问题的长备答案。问题定义一次，比如"这个用户有哪些偏好"，Hindsight 把答案写好存住，后台随着库学到的新东西自动重写这一页。用的时候一次数据库读，不检索、不调 LM。Agent 可以带着一页沉淀好的知识启动，不用每个会话从头再发现一遍。

知识业是精制模型的进一步封装。你给一个名字和一个问题，剩下的决定全是默认值。库给自己写成活文档，像 Wiki 一样组织，可以检索，还能导出成 Markdown 文件。

集成 Agent 是原文里现成的用法：装一个包，给 Claude Code、Codex 这类工具配长期项目记忆。每个仓库一个库，从 Git 历史和过往对话自动建。Agent 开工时这些内容直接注入，再配一页页的知识页写清架构约定和正在进行的工作。

一个库就是一个脑子，归一个用户、一个 Agent 或一个项目。库和库之间严格隔离，不串数据。每个库还可以带性格参数，原文叫 Disposition，比如华裔星、字面主义、同理心，影响 Reflect 时推理的口吻。

适合谁？原文明说：理想用例是那种既要对话又要自主干活的 Agent，官方用的词是 AI 员工，处理开放式任务，根据用户反馈改进行为，学着把复杂任务做到接近人的水平。原文自己也说，只做 n8n 那类简单工作流的话，这套 Overkill、大材小用。

最好的成绩：论文里拿一个开源的 20B 模型当骨干，同一个模型直接读全量上下文基线 39 分，挂上 Hindsight 83.6 分。论文称这套配置超过了全量上下文的 GPT-4o。换更强的骨干，LongMem 到 91.4，另一个基准 LoCoMo 到 89.61。这个榜单上此前最强的开源记忆系统是 75.78。

东西是真的，四类记忆、巩固、反思、常备页这些结构在代码里都翻得到。但产品别急着压一天几千 star 的速成项目，接口和口径说变就变，今天照它的实现细节搭系统，明天一升级就得返工。
