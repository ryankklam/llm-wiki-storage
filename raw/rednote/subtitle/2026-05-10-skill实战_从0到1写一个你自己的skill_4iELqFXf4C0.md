# Skill实战：从0到1写一个你自己的Skill

## 什么是Skill？

一个Skill本质上就是一个**文件夹**，核心是 `skill.md` 这个文档。

```
my-skill/
├── skill.md          # Skill的大脑（元数据 + 操作指南）
├── scripts/          # 需要执行的脚本（可选）
└── reference/        # 模板文件、配置示例等参考材料（可选）
```

`skill.md` 文件相当于Skill的**大脑**，里面写了两部分内容：
- **上面是元数据**：告诉AI"我是谁，我能干什么"
- **下面是操作指南**：告诉AI"我具体应该怎么干"

根据Skill的具体需求，AI还会自动匹配相应的文件夹（如 `scripts/`、`reference/`）。

整个过程由AI引导，**你负责做决策和判断**。

---

## 完整6步流程

### 第1步：想清楚你要解决什么问题

**这一步最关键。** 很多人一上来就写，写了一半发现自己都没想清楚这个Skill到底做什么。

> 问自己一个问题：**"我工作中哪个环节是重复超过三次的？"** 这个环节就值得变成一个Skill。

**示例**：作者之前做每日AI新闻速递，每天都要去好几个网站爬新闻、翻译、整理、排版，流程非常重复，做三天就受不了了——这就是一个完美的Skill场景。

### 第2步：告诉AI你要创建技能

在对话框里说"帮我创建一个新的技能"或"我要做一个某某的Skill"。

**前提条件**：如果已安装 **Claude Code** 和 **Skill Creator** 工具，可以直接说。如果没有，先让AI帮你安装。

### 第3步：回答AI的问题

AI会像**产品经理**一样问你细节，你只需要一一回答。

**第一轮提问**（基本需求）：
- 你希望从哪些网站抓取AI新闻？
- 速递包含哪些内容？（标题、摘要、链接？）
- 输出格式是什么？
- 文件保存在哪个位置？

**第二轮提问**（深层需求）：
- 每天抓取多少条新闻？
- 需不需要自动翻译成中文？
- 提到的自定义网站是哪些？

通过多轮对话，AI会逐步完善你的 `description`，确保Skill能够精准匹配你的需求。

> **为什么description这么重要？** 因为AI靠这段描述来判断需求是否匹配。这就是**按需加载**机制——AI不会把几百个Skill全部读进来，而是先看元数据描述，发现匹配了才会读取详细内容。description写得越精准，AI匹配得越准。

### 第4步：AI自动生成Skill文件

完全由AI完成，等几秒钟即可。AI会根据你的回答自动生成包含完整元数据和详细操作指南的 `skill.md` 文件。

### 第5步：测试和调试

技能创建好以后直接试用。比如作者的"Daily AI News"Skill，只要说"出发速递"，AI就会自动调用Skill执行。

如果发现问题，看AI的执行过程找到偏差，修改 `skill.md` 文件再试一次。**改两三轮基本上就稳了。**

### 第6步：分享你的Skill（最重要的一步）

如果你觉得你的Skill别人也可以用，可以上传到 **GitHub** 或者发布到 **Skill Store** 平台。

Skill也不是写完就完了的，它会**自己长大**——用着用着发现需要调整，随时改 `skill.md` 就行，改一次永久生效。

---

## 核心要点总结

1. **Skill的本质** = 文件夹 + `skill.md`（元数据 + 操作指南）
2. **按需加载机制** = AI先看元数据描述，匹配了才读取详细内容
3. **编写流程** = 想清楚问题 → 告诉AI需求 → 回答问题 → AI生成 → 测试调试 → 分享迭代
4. **无需代码能力** = 整个过程由AI引导，你只做决策
5. **Skill会自己长大** = 随时修改，改一次永久生效

> **建议**：现在去想一个你每天都在重复的事情，花20分钟把它变成你的第一个Skill。
